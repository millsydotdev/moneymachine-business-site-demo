# Turnkey Enterprise React 19 + TypeScript Starter Kit
Compiled & Packaged autonomously by MoneyMachine AI

## Quick Start
1. Extract this archive into your desired workspace directory:
   unzip turnkey-react19-starter-kit-v1.0.0.zip

2. Install dependencies (Node 20+ or Bun 1.1+):
   bun install
   # or
   npm install

3. Start development server with sub-second hot reload:
   bun run dev

4. Compile optimized production build:
   bun run build
   # Outputs directly into ./dist
